# Retail Platform

A full-stack retail order and inventory management system built using Java 21, Spring Boot microservices, Angular, PostgreSQL, and Apache Kafka.

## Project Overview

The platform manages products, inventory, customer orders, and notifications using independently deployable microservices.

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Cloud
- Spring Security and JWT
- Spring Data JPA
- PostgreSQL
- Apache Kafka
- OpenFeign
- Resilience4j

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### DevOps and Infrastructure
- Git and GitHub
- SourceTree
- Maven
- Docker
- Kubernetes
- GitHub Actions
- Prometheus and Grafana

## Planned Microservices
